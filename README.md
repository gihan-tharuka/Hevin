# Hevin

Portfolio website for Ropeholders Media — a static HTML/CSS/JS site with no build step or dependencies.

## Running locally

Serve the site with Python built-in web server:

```bash
cd /Users/gihan/Code/Hevin
python3 -m http.server 8000
```

Then open <http://localhost:8000> in your browser. Press **Ctrl+C** to stop the server. If port 8000 is taken, use another one, e.g. `python3 -m http.server 3000`.
